## การใส่รูปภาพ

เว็บจะสร้างภาพปกจากหน้าแรกของไฟล์ Google Drive ให้อัตโนมัติ (ไฟล์ต้องแชร์แบบ **"ทุกคนที่มีลิงก์"**)
หากต้องการกำหนดรูปเอง ให้เพิ่มคอลัมน์ต่อไปนี้ใน Google Sheet (ไม่ต้องแก้ `code.gs`):

| ชีต | คอลัมน์ | ความหมาย |
|---|---|---|
| `News` | `imageUrl` | ภาพปกข่าว (ลิงก์ Drive หรือ URL รูป) — เว้นว่าง = ใช้หน้าแรกของไฟล์ใน `link` |
| `Documents` | `thumbnail` | ภาพปกเอกสาร — เว้นว่าง = ใช้หน้าแรกของไฟล์ใน `link1` |
| `Stats` | `imageUrl` | ภาพปกรายงานสถิติ (มีอยู่แล้ว) |

ภาพพื้นหลังส่วนหัวหน้าแรก ตั้งค่าที่ `CONFIG.heroImageUrl` ใน `assets/js/app.js`
